# StreamEdge - Level 4: Auto ingest, purge and pre-warm

Levels 1 to 3 built the delivery system. Level 4 adds the daily work of a
content distribution team:

1. **Ingest:** drop an .mp4 in a folder and it is converted to HLS and
   published automatically (Python watcher).
2. **Purge:** remove a video from every edge cache at once, so a wrong or
   replaced video does not keep being served.
3. **Pre-warm:** load a video into every edge before viewers arrive, so the
   first viewers get HITs instead of MISSes.

```
incoming/movie.mp4
      |
      v
 watcher.py --ffmpeg--> origin/www/video/movie/index.m3u8 + segments
                         origin/www/videos.json  (list shown in the player)

 purge.py NAME   --> tells edge1 and edge2 to forget /video/NAME/
 prewarm.py NAME --> requests every file of NAME from edge1 and edge2
```

Files added or changed in this level:

```
streamedge/
  docker-compose.yml       CHANGED: edge1/edge2 also listen on localhost only
  origin/nginx.conf        CHANGED: adds a short cache for videos.json
  origin/www/index.html    CHANGED: video dropdown
  scripts/
    watcher.py             NEW: auto-convert new uploads
    purge.py               NEW: remove a video from all edges
    prewarm.py             NEW: load a video into all edges
  .gitignore               CHANGED: ignores generated files
```

What you learn: automating ingest with Python, atomic publishing, cache
invalidation (the hard part of caching), and cache warming.

Videos now live in their own folders: `video/NAME/index.m3u8` and
`video/NAME/seg_000.ts`. Your old sample video moves to `video/sample/`.

## Step 5: Update nginx.conf (adds a short cache for videos.json)

```bash
cat > origin/nginx.conf << 'EOF'
server {
    listen 80;
    root /usr/share/nginx/html;

    location / {
        add_header Access-Control-Allow-Origin *;
    }

    # Manifest changes, so short cache life
    location ~ \.m3u8$ {
        add_header Cache-Control "public, max-age=2";
        add_header Access-Control-Allow-Origin *;
    }

    # Video list changes when new videos arrive, so short cache life
    location ~ \.json$ {
        add_header Cache-Control "public, max-age=2";
        add_header Access-Control-Allow-Origin *;
    }

    # Segments never change, so long cache life
    location ~ \.ts$ {
        add_header Cache-Control "public, max-age=3600";
        add_header Access-Control-Allow-Origin *;
    }
}
EOF
```

        " | Age: " + r.headers.get("Age") + "s" +
        " | Edge: " + r.headers.get("X-Served-By");
    };

    init();
  </script>

</html>

## Step 8: Create the watcher script

```bash
mkdir -p scripts
cat > scripts/watcher.py << 'EOF'
#!/usr/bin/env python3
"""StreamEdge watcher: converts new .mp4 files in incoming/ to HLS."""
import json
import re
import shutil
import subprocess
import time
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
INCOMING = ROOT / "incoming"
DONE = INCOMING / "done"
FAILED = INCOMING / "failed"
VIDEO_DIR = ROOT / "origin" / "www" / "video"
VIDEOS_JSON = ROOT / "origin" / "www" / "videos.json"
POLL_SECONDS = 2


def log(msg):
    print(time.strftime("%H:%M:%S"), msg, flush=True)


def safe_name(stem):
    return re.sub(r"[^A-Za-z0-9_-]", "-", stem)


def update_index():
    """Write videos.json: the list of finished videos shown in the player."""
    names = sorted(
        p.parent.name
        for p in VIDEO_DIR.glob("*/index.m3u8")
        if not p.parent.name.startswith(".")
    )
    tmp = VIDEOS_JSON.with_suffix(".tmp")
    tmp.write_text(json.dumps(names))
    tmp.replace(VIDEOS_JSON)
    log("videos.json now lists: " + ", ".join(names))


def convert(src):
    name = safe_name(src.stem)
    tmp_dir = VIDEO_DIR / (".tmp-" + name)
    final_dir = VIDEO_DIR / name

    if tmp_dir.exists():
        shutil.rmtree(tmp_dir)
    tmp_dir.mkdir(parents=True)

    cmd = [
        "ffmpeg", "-loglevel", "error",
        "-i", str(src),
        "-c:v", "libx264", "-c:a", "aac",
        "-f", "hls", "-hls_time", "4", "-hls_playlist_type", "vod",
        "-hls_segment_filename", str(tmp_dir / "seg_%03d.ts"),
        str(tmp_dir / "index.m3u8"),
    ]
    log("converting " + src.name + " -> video/" + name + "/")
    result = subprocess.run(cmd, capture_output=True, text=True)
    if result.returncode != 0:
        log("ffmpeg failed: " + result.stderr.strip()[-300:])
        shutil.rmtree(tmp_dir, ignore_errors=True)
        return False

    # Publish in one step: the video appears only when it is complete
    replaced = final_dir.exists()
    if replaced:
        shutil.rmtree(final_dir)
    tmp_dir.rename(final_dir)
    if replaced:
        log("NOTE: '" + name + "' was replaced. Edges may still hold the old "
            "copy. Run: python3 scripts/purge.py " + name)
    log("published " + name)
    return True


def main():
    for d in (INCOMING, DONE, FAILED, VIDEO_DIR):
        d.mkdir(parents=True, exist_ok=True)
    update_index()
    log("watching " + str(INCOMING) + "  (Ctrl+C to stop)")

    last_size = {}
    while True:
        for f in sorted(INCOMING.glob("*.mp4")):
            try:
                size = f.stat().st_size
            except FileNotFoundError:
                continue
            # Only convert when the size stopped changing (upload finished)
            if size > 0 and last_size.get(f) == size:
                ok = convert(f)
                shutil.move(str(f), str((DONE if ok else FAILED) / f.name))
                last_size.pop(f, None)
                if ok:
                    update_index()
            else:
                last_size[f] = size
        time.sleep(POLL_SECONDS)


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        log("stopped")
EOF
```

## Step 9: Create the purge script

```bash
cat > scripts/purge.py << 'EOF'
#!/usr/bin/env python3
"""Remove one video from every edge cache.

Usage: python3 scripts/purge.py VIDEO_NAME
"""
import re
import subprocess
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
EDGES = ["edge1", "edge2"]


def main():
    if len(sys.argv) != 2 or not re.fullmatch(r"[A-Za-z0-9_-]+", sys.argv[1]):
        sys.exit("usage: python3 scripts/purge.py VIDEO_NAME")
    name = sys.argv[1]

    for edge in EDGES:
        # A "ban" tells Varnish: forget every cached object whose URL matches
        cmd = ["docker", "compose", "exec", "-T", edge,
               "varnishadm", "ban", "req.url", "~", "^/video/" + name + "/"]
        r = subprocess.run(cmd, cwd=ROOT, capture_output=True, text=True)
        if r.returncode == 0:
            status = "ok"
        else:
            status = "FAILED: " + (r.stderr or r.stdout).strip()
        print(edge + ": purge /video/" + name + "/ -> " + status)


if __name__ == "__main__":
    main()
EOF
```

## Step 10: Create the pre-warm script

```bash
cat > scripts/prewarm.py << 'EOF'
#!/usr/bin/env python3
"""Load every file of one video into every edge cache.

Usage: python3 scripts/prewarm.py VIDEO_NAME
"""
import re
import sys
import urllib.request
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
VIDEO_DIR = ROOT / "origin" / "www" / "video"
EDGES = {
    "edge1": "http://127.0.0.1:8082",
    "edge2": "http://127.0.0.1:8083",
}


def fetch(base, path):
    with urllib.request.urlopen(base + path, timeout=30) as r:
        r.read()
        return r.headers.get("X-Cache", "?")


def main():
    if len(sys.argv) != 2 or not re.fullmatch(r"[A-Za-z0-9_-]+", sys.argv[1]):
        sys.exit("usage: python3 scripts/prewarm.py VIDEO_NAME")
    name = sys.argv[1]

    manifest = VIDEO_DIR / name / "index.m3u8"
    if not manifest.exists():
        sys.exit("no such video: " + name)

    # The manifest lists the segment files; lines starting with # are tags
    files = ["index.m3u8"] + [
        line.strip()
        for line in manifest.read_text().splitlines()
        if line.strip() and not line.startswith("#")
    ]

    for edge, base in EDGES.items():
        counts = {}
        for fname in files:
            result = fetch(base, "/video/" + name + "/" + fname)
            counts[result] = counts.get(result, 0) + 1
        print(edge + ": " + str(len(files)) + " files -> " + str(counts))


if __name__ == "__main__":
    main()
EOF
```

Check all three files exist:

```bash
ls scripts
```

## Step 11: Restart the system

```bash
docker compose up -d
docker compose restart origin
docker compose ps
```

`up -d` recreates the edges (so their caches are empty). `restart origin`
makes NGINX read the new nginx.conf. You should see origin, edge1, edge2
and lb running.

## Step 12: Start the watcher in the background

```bash
nohup python3 scripts/watcher.py > watcher.log 2>&1 &
sleep 2
cat watcher.log
```

You should see a line saying videos.json lists `sample` (or nothing, if
you skipped Step 4), and "watching ...". To follow it live later:

```bash
tail -f watcher.log
```

(Press Ctrl+C to stop following. That does not stop the watcher.)

To stop the watcher: `pkill -f watcher.py`

"Video" dropdown with `sample`. If the page looks the same as before, wait a
moment and press Ctrl+F5 again.

# Experiments

## Experiment 1: Drop a video in and watch it appear

Make a second test video. Create it outside `incoming` and then move it in,
so the watcher never sees a half-written file:

```bash
ffmpeg -f lavfi -i testsrc2=duration=15:size=640x360:rate=30 \
       -f lavfi -i sine=frequency=660:duration=15 \
       -c:v libx264 -pix_fmt yuv420p -c:a aac /tmp/movie2.mp4
mv /tmp/movie2.mp4 incoming/
tail -f watcher.log
```

Within a few seconds you should see "converting", "published movie2" and
a new `videos.json` line. Press Ctrl+C. Reload the player page: `movie2` is
in the dropdown. Pick it and press play. The original file moved to
`incoming/done/`.

Why the temp folder: the watcher builds the video in a hidden folder and
renames it into place at the end, so viewers never see a half-converted
video.

## Experiment 2: Pre-warm

```bash
python3 scripts/prewarm.py movie2
python3 scripts/prewarm.py movie2
```

First run: mostly MISS on both edges (the edges loaded the files from the
origin). Second run: all HIT. Now press play on movie2 in the browser. The
first viewer gets cache HITs, the point of pre-warming before a big release.

(If you changed the load balancer to `balance uri` in Level 3, only one edge
will serve each file, but warming both is harmless.)

## Experiment 3: The stale cache problem, then the fix

First, upload a **different** video with the **same name**:

```bash
ffmpeg -f lavfi -i smptebars=duration=15:size=640x360:rate=30 \
       -f lavfi -i sine=frequency=880:duration=15 \
       -c:v libx264 -pix_fmt yuv420p -c:a aac /tmp/movie2.mp4
mv /tmp/movie2.mp4 incoming/
tail -f watcher.log
```

The watcher publishes it and prints a NOTE that the edges may still hold the
old copy. Press Ctrl+C, then compare the file size at the origin and through
the edges:

```bash
curl -sI http://localhost:8081/video/movie2/seg_000.ts | grep -i content-length
for i in 1 2 3 4; do curl -sI http://localhost:8080/video/movie2/seg_000.ts | grep -i -E "content-length|x-served-by"; done
```

The origin and the edges show **different sizes**. The edges are still
serving the old video (segments are cached for 1 hour). Viewers see the
wrong content.

Now purge it:

```bash
python3 scripts/purge.py movie2
for i in 1 2 3 4; do curl -sI http://localhost:8080/video/movie2/seg_000.ts | grep -i -E "content-length|x-cache:"; done
```

You see `MISS` first, and the sizes now match the origin. Cache
invalidation is famously hard. This is the simple version of what a real
CDN does when content is replaced or taken down.

# If something goes wrong

- Dropdown is empty or page looks old: press Ctrl+F5. Then check the file
  exists with `cat origin/www/videos.json`. If it is missing, the watcher
  is not running: check `cat watcher.log`.
- Watcher says `ffmpeg: not found`: install it with `sudo apt install -y ffmpeg`.
- The file stays in `incoming/` and nothing happens: it must end in `.mp4`
  (lowercase), and the watcher must be running (`pgrep -f watcher.py`).
- File moved to `incoming/failed/`: the video was not valid. The reason is
  in `watcher.log`.
- Purge says FAILED: run `docker compose ps` and check the edges are
  running. If `varnishadm` is not found, paste me the message.
- Pre-warm says "Connection refused": the edges are not up, or you did not
  do Step 11. Run `docker compose up -d`.
- Video does not play after the move in Step 4: check
  `ls origin/www/video/sample`. The files must be inside that folder.
- Page loads, video won't play after a replace: run the purge script and
  press Ctrl+F5.
